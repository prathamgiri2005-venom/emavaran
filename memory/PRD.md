# Emavaran - Mental Wellness Platform

## Project Overview
A modern, professional website for **Emavaran** - a counseling and mental wellness platform founded by Manvi Giri and Diksha Mago.

## Original Problem Statement
Create a calming, safe, and trustworthy website with soft colors (light blue, beige, white, pastel tones) featuring:
- Home, About, Services, Blog, Book a Session, Contact, Gallery pages
- Calendar-based booking system
- Session duration: 50-60 minutes
- Payment integration (Razorpay - to be added later)

## User Personas
1. **Individuals seeking therapy** - Adults experiencing anxiety, stress, relationship issues
2. **Young adults** - Students and professionals looking for emotional support
3. **Couples** - Seeking relationship counseling
4. **Parents** - Looking for support for themselves or children

## Core Requirements (Static)
- Professional, calming design
- Mobile responsive
- Booking functionality
- Contact form
- Blog for mental health content
- Service descriptions
